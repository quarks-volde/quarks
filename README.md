# Rahul Raghudhas

Personal research website for Rahul Raghudhas, climate scientist at IITM Pune.

Website: https://quarks-volde.github.io/quarks/

The repository contains the complete static website: HTML pages, CSS, research
illustrations, and the downloadable CV. GitHub Pages publishes from `main` at
`/(root)`. The `.nojekyll` file disables theme generation.

The five main pages are Home, Profile, Research, Publications, and Contact.
Research diagrams are conceptual illustrations, with their purpose stated in
captions. The original `/projects/` route remains available for older links.
